Install Movie List

Flutter project by Ali Alsaffar

Android

Download the app and install it on your phone. It needs the internet for posters.

Download for Android (48 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same app in Safari. The browser version reads the JSON file instead of the database.

Open Movie List in the browser
  1. Tap Share in Safari.
  2. Tap Add to Home Screen to keep it as an icon.
Source code is in the private Gitea repo aalsaffar/movie-list.
